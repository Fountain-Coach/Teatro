TeatroCore

Scope
- Pure Swift core: view DSL, layout engine, Fountain parsing, storyboard DSL, renderers (SVG/HTML/Markdown), and MIDI logic/encoders.
- No direct dependencies on SDL or audio backends.

Status
- In this repo, TeatroCore is delivered as a SwiftPM target within the root Package.swift. Full extraction to a `Packages/TeatroCore` standalone package is planned.

Import
- import TeatroCore
